# Plan hybride

App web (PWA) de mon plan course + musculation, publiée avec GitHub Pages : https://koriesza.github.io/plan-koko/

À ajouter à l'écran d'accueil de l'iPhone depuis Safari (Partager › Sur l'écran d'accueil).

- **Séances** : plan semaine par semaine, fiches technique et vidéos par exercice, suivi des charges, Forme du jour.
- **Santé** : import des données Apple Santé via le Raccourci « Plan Santé » (voir [RACCOURCI.md](RACCOURCI.md)), tendances FC de repos / VFC / sommeil / km, derniers entraînements avec zones cardiaques.
- **Allures** : VMA, allures et zones cardiaques.
- **Règles** : gestion de la fatigue, progression, bilan mensuel et sauvegarde.

Les données (séances cochées, charges, données Santé) restent sur le téléphone.
