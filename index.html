      Derniers entraînements

        Configurer le Raccourci Santé (une seule fois, ~15 min)

        Le Raccourci lit tes données Santé et les copie ; l'app les importe d'un tap. Les noms des menus peuvent varier un peu selon ta version d'iOS.

        1. Créer le raccourci

        1. Ouvre l'app Raccourcis, touche +, et nomme-le Plan Santé.

        2. Bloc FC de repos

        1. Ajoute l'action Rechercher des échantillons de santé. Type : Fréquence cardiaque au repos. Ajoute le filtre Date de début · dans les dernières · 21 jours. Trier par Date de début, plus récent d'abord. Pas de limite.
        2. Ajoute Répéter avec chaque élément.
        3. Dans la boucle, ajoute Formater la date : touche la date, choisis Élément répété, puis sa propriété Date de début. Format : Personnalisé, chaîne yyyy-MM-dd'T'HH:mm:ss.
        4. Ajoute Texte et écris : RHR; + la variable Date formatée + ; + la variable Élément répété (touche-la et choisis la propriété Valeur).
        5. Ajoute Ajouter à la variable, nom : Export.

        3. Bloc VFC

        1. Refais exactement le bloc 2 avec le type Variabilité de la fréquence cardiaque (21 jours) et un texte qui commence par HRV;.

        4. Bloc sommeil

        1. Même principe avec le type Analyse du sommeil, filtre 4 jours.
        2. Dans la boucle, mets deux actions Formater la date (même format) : une sur la Date de début, une sur la Date de fin de l'élément répété.
        3. Texte : SLP; + date de début formatée + ; + date de fin formatée + ; + Élément répété › Valeur. Puis Ajouter à la variable Export.

        5. Bloc entraînements (avec la FC)

        1. Rechercher des échantillons de santé, type Entraînements, filtre 3 jours, puis Répéter avec chaque élément.
        2. Dans la boucle : deux Formater la date (début et fin), puis Texte : WK; + début + ; + fin + ; + la propriété distance de l'élément répété + ; + sa propriété type d'entraînement. Ajouter à la variable Export.
        3. Toujours dans la boucle : Rechercher des échantillons de santé, type Fréquence cardiaque, filtre Date de début · est entre · Élément répété › Date de début et Élément répété › Date de fin. Pas de limite.
        4. Juste après, une 2e boucle Répéter avec chaque élément sur ces mesures : Formater la date (Élément répété 2 › Date de début, même format), Texte HR; + date + ; + Élément répété 2 › Valeur, Ajouter à la variable Export.

        6. Fin du raccourci

        1. Après toutes les boucles : Combiner le texte (variable Export, avec Nouvelles lignes).
        2. Copier dans le presse-papiers.
        3. Afficher une notification : Données copiées : ouvre Plan hybride et touche Importer.
        4. Lance-le une fois et accepte les autorisations Santé. Ouvre l'app, onglet Santé, Importer depuis Santé.

        7. Poids et tour de taille (facultatif)

        1. Même principe que le bloc FC de repos, avec le type Poids (60 jours) et un texte qui commence par WT;.
        2. Si tu mesures ton tour de taille dans Santé : type Tour de taille, texte WST;. Sinon, saisis-le dans l'onglet Progrès.

        8. Automatiser

        1. Raccourcis › Automatisation › + › Réveil › « Quand le réveil est arrêté » (ou Heure de la journée, 7:30) › Exécuter immédiatement › raccourci Plan Santé.
        2. Si ton iOS le propose : une 2e automatisation Entraînement Apple Watch › « Se termine » › même raccourci.
        3. Ensuite, chaque matin : ouvre l'app et touche Importer. C'est tout.

        • Séance manquée : sautée, jamais rattrapée en doublant. Priorité : qualité, sortie longue, Muscu A, Muscu B, EF, Muscu C.

        Progression

        • Muscu : toutes les séries en haut de fourchette au RIR cible, alors +2,5 kg (haut, machine), +1 à 2 kg par haltère, +5 kg (machines jambes).
        • Course : jamais volume et intensité en hausse la même semaine. +10 % de volume par semaine maximum, sortie longue plafonnée à 1h45.
        • Protéines 1,6 à 2 g/kg/jour (145 à 180 g). Déficit léger seulement hors veille et jour de qualité ou de sortie longue.
